# Light Scheduler with WebSocket and MQTT

A web-based IoT dashboard to schedule lights using WebSocket and MQTT communication.

## Features

- Set ON/OFF times for lights via a web interface
- Real-time status updates
- MQTT-based communication with hardware
- WebSocket for browser-server communication

## Prerequisites

- Python 3.7+
- Node.js (for development server)
- Mosquitto MQTT broker
- Arduino IDE (for uploading to Arduino)
